教程 1 · 网页版 Google Gemini 任务模式 & 手机端 App

60 秒接入网页版 Gemini 与手机端同步远控

电脑端完成一次连接器绑定后，登录同一 Google 账号的 Android 与 iOS 手机端 Gemini App 自动同步该连接器。

打开 Gemini 连接器设置
  • 第 1 步：确认 Google 账号条件

    需使用年满 18+ 周岁的 Google AI Pro / Ultra 订阅账号，或已由管理员开启自定义连接器权限的 Google Workspace 账号（免费个人账号暂未开放网页端自定义连接器入口）。

  • 第 2 步：填入 Cosmos 名称与 /mcp 地址

    在网页版 Gemini 左侧栏依次点击 Customize（自定义） -> Connectors（连接器） -> + Custom（添加自定义），Name 填 Cosmos，URL 粘贴 https://xxxxx.srv.us/mcp；若展开 Additional settings，Client ID 与 Client Secret 均保持留空。

  • 第 3 步：本机 800ms 免口令放行 或 手机核对配对码

    同机浏览器跳转授权页时，系统通过 800ms 顶层回环桥接校验同机身份，直接点「本机一键允许连接（免输口令）」完成绑定；手机或异地浏览器授权时，核对页面 4 位防钓鱼核对码并输入 6 位动态配对码。

  • 第 4 步：将 App actions 设为 Always allow（始终允许） 并存入守则

    在 Connectors（连接器） 列表点开 Cosmos，把 App actions 总开关设为 Always allow（始终允许）（请勿在聊天对话流弹出的单张工具确认卡片上单独点允许，否则会覆盖其余工具免审批状态）；随后在 Studio 点击「复制 AI 操作守则（推荐存入 Skills）」保存到 Customize（自定义） -> Skills（技能）。

  • 第 5 步：新建对话首句输入 @Cosmos 实测

    新建对话后，在输入框首句输入 @Cosmos 并点选弹出的连接器标签，发送右侧首句测试词即可读取本机目录。

    在 Chat 或 Work 模式让 @WebAI2PC 调用一次 pc_get_status（get_status）确认返回本机系统与开放目录；只读令牌若跨端点请求 /mcp 会直接返回 HTTP 403 forbidden_cross_resource。

教程 3 · 交互式连接方案推荐器

3 类连接通道选型器（点击您的使用需求展开对应步骤）

网页端 AI 从云端访问本机需通过标准 443 HTTPS 加密通道。Studio 内 3 张连接卡片右上角均配独立开关，可同时开启并存互不中断（如同时开启 srv.us 与 Cloudflare Workers），点击下方需求查看配置步骤。

推荐方案 ①：一键上手免登录直连（*.srv.us 持久固定网址 + 4 秒自动回退）

双击 一键启动_Cosmos_MCP.bat（macOS / Linux 运行 ./start_cosmos_mcp.sh）后默认启用：优先用本机持久密钥锁定免登录固定网址 https://*.srv.us/mcp（关机重启网址不变）；若所在校园网或公司网限制 22 端口，系统在 4 秒内自动切换至内置快速通道 https://*.trycloudflare.com 生成可用地址。连上免登录固定网址后，可在卡片内点击「导出身份恢复卡 PNG」备份密钥。

在 Studio「总览与网页连接 -> 第 1 类」可通过卡片右上角独立开关随时启停，支持在「免登录固定网址 (*.srv.us)」与「临时快速通道 (*.trycloudflare.com)」间切换，也可与通道 2、通道 3 同时开启并存互不踢掉。
通道 1 · 命令行等效启动 
cosmos-mcp start --workspace D:\Projects\my-app

推荐方案 ②：Cloudflare 免费固定网关（3 秒部署休眠中继 · 令牌即刻清零）

  1. 在 Studio 展开「通道 2：Cloudflare 专属固定网关」，点击「第 1 步：点此打开 Cloudflare 预填权限页（支持 Google 快捷登录）」生成最小权限 API 令牌。
  2. 将令牌粘贴回「第 2 步：粘贴 API 令牌」（国内网络可选填免费 *.dpdns.org 或自有域名免切代理），点击「一键部署并开启（约 3 秒）」。
  3. 后台约 3 秒自动认领 *.workers.dev 子域并部署免费云端休眠中继网关（Cloudflare Workers）；部署完成后本机立即清零销毁 API 令牌，磁盘零明文留存。
  4. 后续可直接拨动卡片右上角独立开关启停连接（无需重填令牌），可与通道 1、通道 3 同时在线并存；电脑重启、休眠唤醒或切换热点后通过出站 443 WebSocket 自动重连。
通道 2 · 预填令牌页与非交互接入 
cosmos-mcp agent-setup --mode workers_dev --public-url "https://your-worker.your-subdomain.workers.dev" --workspace "D:\Projects\my-app" --autostart --no-browser --json

推荐方案 ③：自有云服务器 24 小时常驻主站 与 Named Tunnel / 自有反代

  • 自有服务器建 24h 主站：在 Studio「第 3 类 -> 自有服务器建 24h 主站」填入公网 IP，支持使用 SSH 密码（仅内存使用不落盘）、填写本地 SSH 私钥路径（如 ~/.ssh/id_ed25519）或勾选本机默认 SSH 密钥免密登录（海外及港澳台服务器免域名自动签发公网 IP HTTPS 证书，内存小于 256MB 自动补充交换分区），点击「一键部署 24h 主站并开启」。电脑关机时仍可操作服务器文件，访问离线电脑路径返回清晰的电脑离线提示（ERR_NODE_OFFLINE）；电脑在线时自动按路径路由到服务器或本机（target="auto"）。
  • 自有固定域名 / Named Tunnel / 自有反代：切换到「自有固定域名 / 通用 HTTPS 反代」填入 https://mcp.example.com 及选填 Named Tunnel 令牌或 SSH 反向映射端口（默认 18096），点击「保存并开启此网关」。

cosmos-mcp start --mode vps --vps-ssh user@vps.example.com --vps-remote-port 18096 --public-url https://mcp.example.com --autostart

    代码与 Word / Excel 修改均支持秒级原样撤回。

教程 6 · 即时关键词筛选与自检命令

常见排障与自检速查

输入报错码（如 NO_PROXY、ERR_OFFICE_FILE_LOCKED、WindowsApps）或点击下方分类标签即时定位解法。

未找到匹配的排障条目，请尝试清空关键词或切换为「全部」。
1. Windows 设了 NO_PROXY 但走系统代理时，网关连接停留重连或无法直连 *.workers.dev 代理与网关
现象：部署通道 2（*.workers.dev）后本地浏览器提示无法直连，或守护进程因环境变量含宽泛 NO_PROXY 影响系统代理识别导致握手超时。
排查与解决：① 若使用规则模式代理软件（如 Clash 规则模式将 workers.dev 设为直连），首次点击连接绑定时请临时切为全局代理 10 秒完成一次性授权（绑定后由 Google / OpenAI 云端直连 Cloudflare，日常无需开全局），或在通道 2 填入自定义域名（如免费 *.dpdns.org）免切代理；② 检查系统环境变量 NO_PROXY 是否误填了 *，运行下方自检命令核实实际生效代理与网关连通性。
2. 热开关扩展包（受管浏览器 / 桌面操控）或改前缀后，Gemini / ChatGPT 对话里没出现新工具 连接器刷新
原因：网页版 Gemini 与网页版 ChatGPT 会在开启对话时缓存当前连接器的工具 Schema 列表，已在途的旧对话不会自动拉取刚开启的扩展包工具。
解决步骤：在 Studio「工具中心与安全开关」打开「受管浏览器包」（pc_browser_use）、「桌面窗口操控包」（pc_cua_window）或点「保存工具前缀」后，前往网页版 Gemini Customize（自定义） -> Connectors（连接器） -> Cosmos 刷新连接器并新建一个对话首句输入 [at]Cosmos；网页版 ChatGPT 请在左侧 Plugins 打开 WebAI2PC 点击 Refresh 刷新，随后新建 Chat 或 Work 对话输入 @WebAI2PC。
3. Windows 11 自动跳过 WindowsApps\python.exe 微软商店空壳解释器机制 Python 环境
现象：全新 Windows 11 电脑默认在 PATH 注入了 WindowsApps\python.exe 商店引导空壳，手动敲命令不执行脚本反而弹出商店。
内置处理与指定方法：一键启动_Cosmos_MCP.bat 与守护进程会自动识别并跳过 WindowsApps\python.exe 空壳，按顺序优先使用随包 python-embed 免装环境、已就绪的 .venv，或自动扫描本机官方 Python 3.10 至 3.14、Conda 与 uv 解释器；如需为特定项目固定环境，可在 Studio「工作区与 Python 环境 -> 默认 Python / Conda 解释器环境」下拉框选择并点击「保存解释器路径」。
4. Word 或 Excel 正在打开占用文档时的写入保护提示（ERR_OFFICE_FILE_LOCKED） 写入保护
现象：让 @Cosmos 修改 .docx 或 .xlsx 文件时返回 ERR_OFFICE_FILE_LOCKED。
原因与解决：当目标文件正被本地 Word 或 Excel 打开（目录中存在 ~$ 临时锁文件或操作系统文件句柄独占）时，pc_edit_file 自动拒绝强行写入，避免冲掉您窗口中尚未保存的手工编辑。请先在 Word / Excel 中按 Ctrl+S 保存并关闭该文档，再回到聊天窗口让 AI 重试即可。
5. 笔记本电池供电自动解除防休眠机制 与 物理合盖断网说明 电源与休眠
机制说明：开启首屏「插电防自动休眠」开关后，台式机与插着交流电源的笔记本会自动维持系统唤醒状态，防止息屏断连；当笔记本拔掉电源改用电池供电时，系统会自动解除防休眠以保护电池续航（此外物理合上笔记本盖子仍会触发主板硬件休眠断网）。
远程常驻建议：外出需要用手机 Gemini App 远程操控家中或工位笔记本时，请保持笔记本连接电源适配器且不合盖（可将屏幕亮度调至最低），开盖唤醒或网络切换后约 1.5 秒内会自动重连网关；也可通过通道 3 部署 24h 云服务器主站。
6. 网页版 Gemini 每次调用不同工具都弹出确认卡片，未实现连贯执行 免审批配置
原因：在聊天流弹出的单张工具确认卡上单独点允许，只会针对该单个工具写入局部规则并导致同连接器下其他工具退回逐次确认；或者 Studio 开启了宿主确认开关。
解决步骤：① 打开网页版 Gemini Customize（自定义） -> Connectors（连接器） -> Cosmos，将 App actions 总开关设为 Always allow（始终允许）；② 在本地 Studio「工具中心与安全开关」确认「写文件与运行命令前向宿主请求确认」处于关闭状态。
