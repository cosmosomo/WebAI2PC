教程 1 · 网页版 Google Gemini 任务模式 & 手机端 App

60 秒接入网页版 Gemini 与手机端同步远控

电脑端完成一次连接器绑定后，登录同一 Google 账号的 Android 与 iOS 手机端 Gemini App 自动同步该连接器。

打开 Gemini 连接器设置
  • 第 1 步：确认 Google 账号条件

    需使用年满 18+ 周岁的 Google AI Pro / Ultra 订阅账号，或已由管理员开启自定义连接器权限的 Google Workspace 账号（免费个人账号暂未开放网页端自定义连接器入口）。

  • 第 2 步：打开 Gemini 连接器设置，把 /mcp 地址粘到配置栏（勿直接浏览器打开）

    注意：不要把 https://xxxxx.srv.us/mcp 直接粘贴到浏览器地址栏里打开。请点击右上角按钮直接访问 https://gemini.google.com/customize/connectors（或从 Gemini 首页左下角菜单依次点击 Personal Intelligence -> Connected Apps），点击右上角 + Custom，在弹出的 Connect to an MCP server 窗口把该地址粘贴到 MCP Server URL 配置栏（Additional settings 保持默认折叠），点击 Next。

    查看 4 步实拍截图教程 点击展开，支持点击放大
  • 第 3 步：本机 800ms 免口令放行 或 手机核对配对码

    同机浏览器跳转授权页时，系统通过 800ms 顶层回环桥接校验同机身份，直接点「本机一键允许连接（免输口令）」完成绑定；手机或异地浏览器授权时，核对页面 4 位防钓鱼核对码并输入 6 位动态配对码。

  • 第 4 步：将 App actions 设为 Always allow（始终允许） 并存入守则

    回到 gemini.google.com/customize/connectors 点开刚添加的连接器，把 App actions 总开关设为 Always allow（始终允许）（请勿在聊天对话流弹出的单张工具确认卡片上单独点允许，否则会覆盖其余工具免审批状态）；随后在 Studio 点击「复制 AI 操作守则（推荐存入 Skills）」保存到 Gemini 的 Skills 中。

  • 第 5 步：新建对话首句输入 @Cosmos 实测

    新建对话后，在输入框首句输入 @Cosmos 并点选弹出的连接器标签，发送右侧首句测试词即可读取本机目录。

教程 3 · 交互式连接方案推荐器

3 类连接通道选型器（点击您的使用需求展开对应步骤）

网页端 AI 从云端访问本机需通过标准 443 HTTPS 加密通道。Studio 内 3 张连接卡片右上角均配独立开关，可同时开启并存互不中断（如同时开启 srv.us 与 Cloudflare Workers），点击下方需求查看配置步骤。

通道方案 本机组件依赖 配额与超时边界 网络与代理要求（含国内边界）
通道 1 默认：*.srv.us 系统自带 OpenSSH（ssh）+ 出站 TCP 22，零额外二进制 免注册，重启网址固定不变 国内家庭宽带通常免代理直连（22 受阻 4 秒回退 trycloudflare）
通道 1 回退：*.trycloudflare.com 官方 cloudflared（未装时首次从 GitHub Releases 或 COSMOS_CLOUDFLARED_MIRROR 自动下载至 bin/） 重启必换域名，无 SLA，单流 ha-connections:1 重连空窗 4–21s（返 530/1033），限 200 并发与 125s 读超时 国内无代理拉取 GitHub 慢时需开代理、设 COSMOS_CLOUDFLARED_MIRROR 或预装；高丢包建议开 HTTP 代理
通道 2：Cloudflare 专属固定网关（workers_dev） 纯 Python 标准库 443 WSS，零外部二进制依赖（免装 Node.js / wrangler / cloudflared） Workers Free 每日 100,000 次请求上限（超限返 1027），边缘默认反代读超时 125s 国内默认 *.workers.dev 遭全量 DNS 污染（裸连 100% 超时），运行期间须保持系统 HTTP/HTTPS 代理常开且规则覆盖 *.workers.dev（NO_PROXY 保留 127.0.0.1,localhost,::1）；绑同账号 Active Zone 自定义域名可免代理直连
通道 3 主推：自有服务器 24h 主站（vps_hub / vps） 本机 ssh 客户端 + 开放 80/443 端口的 Linux 服务器 零 Cloudflare 依赖、零单日请求上限、零 125s 边缘超时，关机主站仍在线 国内（配已备案域名）或港新服务器全程免代理直连
通道 3 子项：Cloudflare Named Tunnel（cloudflare_token） 官方 cloudflared（同上自动下载或 COSMOS_CLOUDFLARED_MIRROR） 需 Zero Trust 账号 + Active Zone 域名 + 转发至 http://127.0.0.1:8096，边缘读超时 125s 自定义域名免受 workers.dev 污染；须在后台关闭 Bot Fight Mode 并对 /mcp* 与 OAuth 路径跳过托管质询

推荐方案 ①：一键上手免登录直连（*.srv.us 持久固定网址 + 4 秒自动回退）

双击 一键启动_Cosmos_MCP.bat（macOS / Linux 运行 ./start_cosmos_mcp.sh）后默认启用：优先通过系统自带 OpenSSH（ssh）锁定免登录固定网址 https://*.srv.us/mcp（关机重启网址不变，国内家庭宽带通常免代理直连）；若校园网或企业网封禁出站 22 端口，系统在 4 秒内自动切换至快速通道 https://*.trycloudflare.com（首次需从 GitHub Releases 或 COSMOS_CLOUDFLARED_MIRROR 自动下载 cloudflared 至 bin/；注意该临时通道每次重启必换域名、无 SLA、单流重连有 4–21 秒空窗返 530/1033 且限 200 并发）。连上免登录固定网址后，可在卡片内点击「导出身份恢复卡 PNG」备份密钥。

在 Studio「总览与网页连接 -> 第 1 类」可通过卡片右上角独立开关随时启停，支持在「免登录固定网址 (*.srv.us)」与「临时快速通道 (*.trycloudflare.com)」间切换，也可与通道 2、通道 3 同时开启并存互不踢掉。
通道 1 · 命令行等效启动 
cosmos-mcp start --workspace D:\Projects\my-app

推荐方案 ②：Cloudflare 免费固定网关（纯 Python 零外部二进制 · 令牌即刻清零）

  1. 在 Studio 展开「通道 2：Cloudflare 专属固定网关」（本机纯 Python 443 WSS 实现，无需装 Node.js、wrangler 或 cloudflared），点击「第 1 步：点此打开 Cloudflare 预填权限页（支持 Google 快捷登录）」生成最小权限 API 令牌。
  2. 将令牌粘贴回「第 2 步：粘贴 API 令牌」（国内若想免代理直连，请选填同一 Cloudflare 账号下已激活的自定义域名 Active Zone，如 mcp.yourdomain.dpdns.org），点击「一键部署并开启（约 3 秒）」。
  3. 后台约 3 秒自动认领 *.workers.dev 子域并部署免费休眠中继网关（受 Workers Free 每日 100,000 次请求上限与边缘 125s 读超时约束）；部署完成后本机立即清零销毁 API 令牌，磁盘零明文留存。
  4. 中国大陆代理依赖边界：*.workers.dev 在国内存在全量 DNS 污染（裸连 100% 超时）。未绑定自定义域名时，本机运行期间须保持系统 HTTP/HTTPS 代理（Clash / Mihomo / v2rayN 或 HTTPS_PROXY / WSS_PROXY）常开且分流规则覆盖 *.workers.dev（首次浏览器打开 /consent 亦需代理，NO_PROXY 须保留 127.0.0.1,localhost,::1）；绑定同账号自定义域名后可免代理直连。

推荐方案 ③：自有云服务器 24 小时常驻主站 与 Named Tunnel / 自有反代

  • 自有服务器建 24h 主站（免代理 · 零配额限制）：依赖开放 80/443 端口的 Linux 服务器与本机 ssh 客户端（零 Cloudflare 依赖、零单日请求上限、零 125s 边缘超时，国内或港新服务器全程免代理直连）。填入公网 IP 与 SSH 密码或密钥点击「一键部署 24h 主站并开启」，电脑关机时仍可操作服务器目录（离线电脑路径返回 ERR_NODE_OFFLINE），在线时支持 target="auto" 跨机路由。

教程 6 · 即时关键词筛选与自检命令

常见排障与自检速查

输入报错码（如 NO_PROXY、ERR_OFFICE_FILE_LOCKED、WindowsApps）或点击下方分类标签即时定位解法。

未找到匹配的排障条目，请尝试清空关键词或切换为「全部」。
1. Windows 设了 NO_PROXY 但走系统代理时，网关连接停留重连或无法直连 *.workers.dev 代理与网关
现象：在中国大陆部署通道 2（*.workers.dev）后，浏览器打不开 /consent 授权页，或关闭代理、规则将 *.workers.dev 直连后本机后台 443 WSS 持续握手超时。
排查与解决：① *.workers.dev 在国内遭全量 DNS 污染（裸连 100% 超时）：未绑定自定义域名时，本机运行期间必须保持系统 HTTP/HTTPS 代理常开且分流规则代理访问 *.workers.dev（首次授权若规则漏掉 *.workers.dev 可临时切全局完成授权，但切回规则模式后仍须确保 *.workers.dev 走代理）；若想国内免代理直连，请在通道 2 绑定同一 Cloudflare 账号下的自定义域名（Active Zone，并关闭 Bot Fight Mode），或改用通道 1 *.srv.us / 通道 3 自有服务器；② 若设置了环境变量 NO_PROXY，必须保留 127.0.0.1,localhost,::1 且勿写入 * 或 *.workers.dev，可运行下方自检命令核对。
2. 热开关扩展包（受管浏览器 / 桌面操控）或改前缀后，Gemini / ChatGPT 对话里没出现新工具 连接器刷新
原因：网页版 Gemini 与网页版 ChatGPT 会在开启对话时缓存当前连接器的工具 Schema 列表，已在途的旧对话不会自动拉取刚开启的扩展包工具。
解决步骤：在 Studio「工具中心与安全开关」打开「受管浏览器包」（pc_browser_use）、「桌面窗口操控包」（pc_cua_window）或点「保存工具前缀」后，前往网页版 Gemini gemini.google.com/customize/connectors（或左下角菜单 Personal Intelligence -> Connected Apps）点开对应连接器 刷新连接器并新建一个对话首句输入 @Cosmos；网页版 ChatGPT 请在左侧 Plugins 打开 WebAI2PC 点击 Refresh 刷新，随后新建 Chat 或 Work 对话输入 @WebAI2PC。
3. Windows 11 自动跳过 WindowsApps\python.exe 微软商店空壳解释器机制 Python 环境
现象：全新 Windows 11 电脑默认在 PATH 注入了 WindowsApps\python.exe 商店引导空壳，手动敲命令不执行脚本反而弹出商店。
内置处理与指定方法：一键启动_Cosmos_MCP.bat 与守护进程会自动识别并跳过 WindowsApps\python.exe 空壳，按顺序优先使用随包 python-embed 免装环境、已就绪的 .venv，或自动扫描本机官方 Python 3.10 至 3.14、Conda 与 uv 解释器；如需为特定项目固定环境，可在 Studio「工作区与 Python 环境 -> 默认 Python / Conda 解释器环境」下拉框选择并点击「保存解释器路径」。
4. Word 或 Excel 正在打开占用文档时的写入保护提示（ERR_OFFICE_FILE_LOCKED） 写入保护
现象：让 @Cosmos 修改 .docx 或 .xlsx 文件时返回 ERR_OFFICE_FILE_LOCKED。
原因与解决：当目标文件正被本地 Word 或 Excel 打开（目录中存在 ~$ 临时锁文件或操作系统文件句柄独占）时，pc_edit_file 自动拒绝强行写入，避免冲掉您窗口中尚未保存的手工编辑。请先在 Word / Excel 中按 Ctrl+S 保存并关闭该文档，再回到聊天窗口让 AI 重试即可。
5. 笔记本电池供电自动解除防休眠机制 与 物理合盖断网说明 电源与休眠
机制说明：开启首屏「插电防自动休眠」开关后，台式机与插着交流电源的笔记本会自动维持系统唤醒状态，防止息屏断连；当笔记本拔掉电源改用电池供电时，系统会自动解除防休眠以保护电池续航（此外物理合上笔记本盖子仍会触发主板硬件休眠断网）。
远程常驻建议：外出需要用手机 Gemini App 远程操控家中或工位笔记本时，请保持笔记本连接电源适配器且不合盖（可将屏幕亮度调至最低），开盖唤醒或网络切换后约 1.5 秒内会自动重连网关；也可通过通道 3 部署 24h 云服务器主站。
6. 网页版 Gemini 每次调用不同工具都弹出确认卡片，未实现连贯执行 免审批配置
原因：在聊天流弹出的单张工具确认卡上单独点允许，只会针对该单个工具写入局部规则并导致同连接器下其他工具退回逐次确认；或者 Studio 开启了宿主确认开关。
解决步骤：① 打开网页版 Gemini gemini.google.com/customize/connectors（或左下角菜单 Personal Intelligence -> Connected Apps）点开对应连接器，将 App actions 总开关设为 Always allow（始终允许）；② 在本地 Studio「工具中心与安全开关」确认「写文件与运行命令前向宿主请求确认」处于关闭状态。
  • 自检项 1：确认网关握手正常（无 NO_PROXY 误拦或规则分流阻断）

    本地 Studio 顶部状态灯显示绿色在线运行。

  • 自检项 2：开启扩展包或修改工具前缀后新建对话加载最新工具 Schema

    确保 pc_browser_use 或 pc_cua_window 在新会话中立即可调。

  • 自检项 3：让 AI 修订 Word / Excel 前先保存关闭本地打开的对应文档

    避免触发 ERR_OFFICE_FILE_LOCKED 锁表保护。

  • 自检项 4：外出手机远控笔记本前确认已连接交流电源且未合盖

    利用交流电自动防休眠保持全天稳定在线。
