# 03. Cosmos Studio Console, Windows Tray & Extension Packs Guide

> **English** | [简体中文](../03_Cosmos_Studio面板与扩展包指南.md) · [Docs Hub](README.md) · [README_EN](../../README_EN.md)

`Cosmos Studio` is the built-in visual control console launched alongside the server. Use it to copy HTTPS endpoints for Web Gemini and Web ChatGPT, open the built-in interactive tutorial center (`/tutorials`), switch among 4 light/dark theme packs and 4 IP icon poses, toggle 3 connection gateways independently, manage read/write layered workspaces and 4 security tiers, hot-toggle peripheral extension packs, and restore file snapshots.

## 1. Windows System Tray, Power Policy & Emergency Read-Only Stop

- **Windows Tray 4-Color Status Indicator & Context Menu**: When running in a Windows desktop session, a status dot stays in the taskbar notification area (green: public gateway connected and web session active; blue: local service ready; orange: tunnel reconnecting; red: connection error). On network issues, it silently updates the tray color, hover tooltip, and console status banner indicating local proxy shutdown or network loss—with zero intrusive system balloon popups stealing focus. Right-click the tray icon to open the console, copy the MCP URL, copy the first-message wakeup prompt, or switch to Read-Only mode. The tray icon can also be hot-toggled in the console (`tray_enabled`).
- **Smart AC vs. Battery Sleep Prevention for Laptops**: With the top-right **"Prevent Auto-Sleep on AC Power (Closing Lid Still Disconnects)"** switch enabled, desktops and laptops plugged into AC power stay awake to prevent 15-minute idle disconnects. When unplugged onto battery power, sleep prevention automatically releases to save battery, and the gateway reconnects within ~1.5 seconds upon wake.
- **Single-Passcode Session Unlock & Zero-Passcode Emergency Read-Only**: Before modifying settings over remote access, enter the local passcode once at the top of the console to unlock (issues a 12-hour `HttpOnly` session cookie; direct localhost connections are authorized automatically). Selecting `Read-Only` (`只读`) on the **"Current Permissions"** 4-tier bar on the home page (or on `Settings -> Tools & Extensions`, or "Switch to Read-Only Mode" in the system tray right-click menu) immediately drops to `L1` Read-Only mode without requiring a passcode and terminates all in-flight commands and peripheral sessions within `0.1` seconds.

## 2. Five Console Feature Pages

1. **Overview & Web Connection**:
   - Displays the active HTTPS endpoint, 6-digit dynamic pairing code, and backup passcode tailored to Web Gemini (bind `/mcp`, recommended name `WebAI2PC` or `Cosmos`) and Web ChatGPT (bind `/mcp` for Team / Enterprise Workspace accounts, `/mcp/readonly` for Personal Plus / Pro accounts, recommended name `WebAI2PC`). Once the gateway is ready, the ChatGPT tab unlocks **`复制一键配置提示词（发给 Work）` (Copy 1-Click Setup Prompt for Work)** and **`复制只读配置提示词（发给 Work）` (Copy Read-Only Setup Prompt for Work)** so `@Plugin Creator` connects over standard OAuth 2.1 in `Work` mode; once installed, switch back to `Chat` mode with `@<your-connector-name>` (default `@WebAI2PC`) for zero `Work / Codex` quota burn. Also provides **"Copy AI Operational Rules"** and, right after authorization completes, displays a green connected banner with a **"1-Click Copy Wakeup Test Prompt"** button.
   - **Concurrent Multi-Gateway Independent Switches**: All 3 connection cards have independent toggles and live status badges in their top-right corners, allowing multiple gateways to stay online simultaneously (e.g., `srv.us` and `Cloudflare Workers` running side by side without disconnecting each other). Click any connected card to switch the active URL shown and copied in the top bar:
     1. **Built-in OpenSSH Direct Connect**: Works out of the box with zero registration and zero extra binaries; invokes your OS built-in `ssh` client via the public `srv.us` relay for a persistent fixed `https://xxxxx.srv.us` URL (`10`-second startup wait budget), provides an independent backup toggle inside the card for temporary `*.trycloudflare.com` (usable concurrently or when port `22` is blocked), and supports same-machine "1-Click Local Allow (No Passcode Required)".
     2. **Cloudflare Free Permanent URL**: Click the pre-filled token link, paste once, and deploy a free SQLite Durable Object hibernating gateway (e.g., `https://your-worker.your-subdomain.workers.dev`) in ~3 seconds for a permanent URL. The token is immediately wiped, and future start/stop uses only the card toggle.
     3. **Your Own Server & Domain**: Enter a server IP with an SSH password, local SSH private key path, or default SSH key for 1-click deployment of a 24/7 hub managing both the server and your local PC, or bind a Cloudflare Named Tunnel token / custom reverse-proxy domain.
   - **Top Bar Interactive Tutorials & Theme Switcher**: The right side of the top bar offers a **"Tutorials"** button leading to the 6-chapter, 24-step `/tutorials` interactive guide, language switcher, a **Dark / Light Mode** toggle, and **"Appearance"** settings supporting 4 light/dark style packs (`warm-paper`, `obsidian-emerald`, `cupertino-frost`, `graphite-mono`), 4 IP icon packs, and 4 gaze poses (appending `?debug=1` to the URL also reveals the promo `StylePack JSON` export button).
   - Lists active connected web sessions with single-session disconnect or **"Disconnect All"** revocation.
2. **Workspace & Python Environment**:
   - **Native Folder Picker & Quick-Add Common Directories**: Clicking **"Select Local Folder"** opens the OS-native folder dialog (Windows 64-bit `IFileOpenDialog`, macOS `osascript`, Linux `zenity` / `kdialog`, automatically falling back to an in-page directory tree when no GUI session is present) and scans common local code folders for 1-click addition. On first launch with no prior config, it creates and opens `~/CosmosWorkspace` by default.
   - **Read-Only Reference Directories + Child Project Read-Write Layering**: Add standalone read-only reference directories or configure each added directory independently as **"Read-Write"** (`workspace_roots`) or **"Read-Only Parent / Reference"** (`readonly_workspace_roots`). When an outer code root is set to read-only reference while an inner active project is set to read-write, both the server and child-process sandbox resolve permissions by longest path prefix—preventing accidental writes to sibling repositories with `ERR_READONLY_WORKSPACE`.
   - **Python Environment Picker**: Automatically scans cached `.venv`, `python-embed`, official Python, Conda, and `uv` environments for `pc_run_python` and `pc_bg_command`.
3. **Tool Center & Safety Switches**:
   - Instant hot-switching across **4 security tiers**: `L3` Workspace Dev (default recommended), `L4` Full-Disk Dev (unrestricted directories across the disk while keeping `.trash/` and credential isolation), `L2` Edit Files Only (disables command execution), and `L1` Read-Only Browse. Also hot-toggles the **"Managed Browser Pack"** and **"Desktop Window Control Pack"**, updates `tool_prefix`, or toggles **"Scan Local Global Skill Directories (e.g., `.claude` / `.codex`)"** (off by default to isolate external client directories).
   - Built-in multi-format read-only extraction and zero-C-extension safe `.docx` / `.xlsx` editing: `pc_read_file` views local images directly and extracts text from PDF, `.docx`, `.xlsx`, and `.pptx`; `pc_edit_file` replaces `.docx` paragraph and table text across `<w:r>` runs (preserving first-run typography) or updates `.xlsx` cells and formulas by `Sheet!A1` coordinates. If a document is currently open and locked by Word or Excel (`~$` lock file or open handle), it returns `ERR_OFFICE_FILE_LOCKED` to protect the original file, automatically saves a binary pre-edit snapshot, and supports exact rollback in the console or via `pc_manage_files(action="undo")`.
4. **Live Jobs & Change Recovery**: Monitor running background jobs (`pc_bg_command`) with tail logs, click **"Terminate All In-Flight Jobs"**, inspect pre-edit file and Office document snapshots with Diff comparison and rollback, and review the operational audit log.
5. **Skill Center**:
   - Includes four sub-tabs: **"Local Skills & Details"**, **"Online Marketplace & Audit Install"**, **"New Skill"**, and **"Safe Trash"**, running a 3-tier AST security check before installing or creating managed skills. By default, it loads only `.agents/skills` in open workspaces, the built-in `cosmos-mcp-guide` rules, and the managed `skills_store`.

## 3. Managed Browser Extension Pack (`browser` -> `pc_browser_use`)

After enabling the **"Managed Browser Pack"** (or running `cosmos-mcp permissions --enable-pack browser`), `pc_browser_use` becomes available in `L3` and `L4` modes (optionally install Playwright via `pip install ".[browser]"`; otherwise it automatically reuses local Edge / Chrome / Chromium over headless CDP).

- **Isolated Profile & Download Routing**: Always runs in a dedicated `<state_dir>/browser_profile` directory without reading or touching your personal browser windows. Built-in synchronous SSRF guard blocks `file://`, cloud metadata endpoints, and protected local ports; browser downloads are saved to the active read-write workspace directory by default.
- **True DOM Visibility Filtering**: `snapshot`, `click`, `fill`, and `select` check `display`, `visibility`, `opacity`, and non-zero bounding boxes across elements and ancestors. When hidden mobile forms and visible desktop forms share names, it targets the visible control automatically, returning `ok=False` with `ERR_ELEMENT_HIDDEN` if all matches are hidden.
- **Supported Actions**: `open`, `snapshot` (returns visible interactive node refs such as `e1`, current `scroll_y`, and `scroll_height`), `click`, `fill`, `select`, `scroll`, `list_tabs`, `switch_tab`, `open_login_window` (opens a managed login window via `SW_SHOWNOACTIVATE` without stealing focus so you can scan QR codes manually), `screenshot`, `evaluate`, and `close`.

## 4. Windows Desktop Window Control Pack (`desktop` -> `pc_cua_window`)

On Windows, enabling the **"Desktop Window Control Pack"** (or running `cosmos-mcp permissions --enable-pack desktop`) unlocks `pc_cua_window` in `L3` and `L4` modes. On macOS and Linux, registration of this pack is automatically skipped at startup.

- **Zero Focus Stealing & Scope Fencing**: Uses offscreen `PrintWindow(2)` capture and background window messages exclusively, verifying on every call that foreground focus is unchanged, the physical cursor did not move, and clipboard content has zero delta. In `L3` mode, it only enumerates and operates on windows belonging to open workspace directories or spawned by the current session. Returns `ERR_SCREEN_LOCKED_OR_BLACK_FRAME` on locked/black screens and blocks closing windows that show unsaved indicators.
- **Scale Coordinate Inversion & Key Synthesis**: Captures of large windows (`> 1440px` long edge) automatically cache `scale_factor` per handle so subsequent `click`, `double_click`, `right_click`, `type_text`, and `scroll` calls under default `coord_space="auto"` map back to exact client-area pixels. Multi-input forms recursively locate target child control handles by coordinate; `send_keys` parses `ctrl+s`, `ctrl+shift+z`, `alt+f4`, arrow keys, and function key combinations.

## 5. System-Level Isolation via `sandbox/`

Beyond application-level directory guardrails, the repository's `sandbox/` folder provides two OS-level isolation configurations:

1. **Unprivileged Docker Container (Linux / macOS / Windows Docker Desktop)**:
   ```bash
   COSMOS_HOST_WORKSPACE=/path/to/project docker compose -f sandbox/docker-compose.yml up -d --build
   ```
   Runs as non-root user `cosmos` (`1000:1000`) with `no-new-privileges:true` and `cap_drop: ALL`, mounting only the designated project directory.
2. **Windows Sandbox Disposable Lightweight VM (Windows 10/11 Pro or Enterprise)**:
   Create a `workspace` folder next to the project and double-click `sandbox/CosmosMCP_WindowsSandbox.wsb` to mount the program directory read-only inside an isolated VM and start the server; closing the sandbox window destroys the runtime environment automatically.
